From pasted code to a greener version in four steps

  1. SubmitPaste, write or upload Python and choose the input size N.
  2. AnalyzeGet complexity, runtime, energy and CO₂e estimates.
  3. OptimizeReview the bottlenecks and a suggested rewrite.
  4. CompareSee original and optimized results side by side.

What you get

Performance analysis

Time complexity and runtime across growing input sizes, with the loops that cause them.

Energy monitoring

Watt-hours per run, so efficiency is a number you can track and budget.

Carbon footprint

Energy converted to grams of CO₂e, scaled to how often your code runs.

Code optimization

A rewritten version with changed lines highlighted and the savings quantified.
